# OMP global guidance

Edit the harness source; `omp-config/install` composes shared guidance into
`$(omp config path)/AGENTS.md`. Repository `AGENTS.md` adds local context.

Model routing and account policy live in `config.yml` and `models.yml`; use
`omp usage` for current capacity. Read the resolved model/thinking badge on
each task result: a child's configured route is independent of its parent.
Route visual, motion, UX and communications work through `designer` or image-question `read`; source policy
and its checks own the approved model selection. Restart after a binary/catalog
update to load new model IDs.

Prefer Cloudflare for new edge/object-storage infrastructure and exe.dev for
persistent Linux execution. Durable state has one authority and a proven
restore path.

Track Misty Step/personal work in Linear (team `MIS`); R90 work stays in Habitat
and R90's own tools. Linear scope is `~/development/misty-step` and
`~/development/moomooskycow`. Native MCP is the first path; the GraphQL fallback
uses `workstation/LINEAR_API_KEY` through `pass-env`.
Read `$(omp config path)/OPERATIONS.md` when these OMP-specific workflows arise.
