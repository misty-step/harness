# Engineering operations

The existing request/ticket owns why and victory. Do not create a work record for
routine engineering. Use the repository's runnable commands and existing checkout.

## Work records

Glass is the backlog for Misty Step and personal scopes; R90 stays in Habitat.
Use `glass ticket show ID` for intent and `glass query items --scope company/repository`
for live read-only records. A repository scope is `misty-step/name` or
`moomooskycow/name`, never an R90 ticket copied into Glass.

Glass mutations belong to the authorized live-store owner. OMP's engineer boundary
mounts only the read socket, not that store: hand the desk/parent the existing id, scope,
proposed change and evidence; do not write a private or empty fallback store.
New backlog captures require a plain title, description and why with honest
attribution, status `later`, no explicit rank, and historical links in notes.
Only quote Phaedrus when they are his words. Keep one record, not a second ledger.
