# Check cadence (US-023)

Run affected native checks and the shortest changed user path. Use `ship-loop`
for review order, PR round state and final judgment. Documents and measurements
get light combined QA/review and an independent judge.

Documents-only proof reads the changed published or rendered text and checks
affected links or commands. Installed guidance or configuration is installed,
loaded and read. A full product journey applies when that journey changes.
After a fix, recheck only the judge's named blockers and regressions from the fix;
link existing results for unchanged behavior. Shipping includes merge, delivery
and proof of the changed user path.
