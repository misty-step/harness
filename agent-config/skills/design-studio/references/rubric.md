# Divergence and critique

Name each concept's stance and surface archetype before tokens:
monitor, operate, compare, configure, decide/learn, explore, or command/inspect.
Meaningful alternatives differ in several dimensions, including structure or
behavior; palette/typography changes alone are skins.

| Dimension | Useful contrast |
| --- | --- |
| User job | monitor status / inspect one object / decide |
| Navigation/content | table / timeline / map / search / document |
| Layout | column / master-detail / canvas / split panes / stream |
| Hierarchy/density | compact / editorial / progressive |
| Typography | single scale / display-body roles / data-mono |
| Palette/material | flat / layered / line-art / tonal |
| Components | rows / cards / clusters / threads |
| Interaction/motion | keyboard-first / pointer-first / purposeful reveal |
| Organization | object / time / person / phase |

The set spans conservative evolution, a restructured major axis, and a radical
organization/interaction model. A labeled wildcard can challenge the frame.
Fix a cosmetic-only divergence claim at the assignment, not in the paint.

Critique against the primary job: what each optimizes, sacrifices, wins for,
and fails on; name graftable pieces and a survive/merge/reject verdict.
Explain rejection and recommendations through evidence, reference principles,
and constraints. Numeric taste scores and model votes provide no objectivity.

Recombine surviving structure and useful grafts into a real synthesis; preserve
sources and reasons for dropped pieces. Focused tasks use fewer variants and
one clear density/hierarchy/motion axis each, with concise critique and a
refined result. A recolor is not exploration.
