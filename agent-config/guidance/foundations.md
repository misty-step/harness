## Foundations

Every project keeps the foundations in the constitution, `skill://foundation/constitution.md` (`skills/foundation/constitution.md` relative to this file); read it when planning work in a project. In a repository with `foundation.json`, `foundation-check check` lists what the repository still owes. A repository's invariants and review rules belong in its `DOMAIN.md` invariants ledger; its `AGENTS.md` holds operating instructions and routing.

Standing operator approval (2026-09-26) covers agent-opened adoption, pin-bump, gap-closing and invariants-ledger pull requests in every misty-step and r90group repository. Each still passes the repository's gate and, where required, its designated reviewer. Adding or widening an obligation, or removing an escape, needs Phaedrus's approval (ADR-006).
