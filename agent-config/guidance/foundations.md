## Foundations

Every project keeps the foundations in `skill://foundation/constitution.md`; read it when planning work in a project. In a repository with `foundation.json`, `foundation-check check` lists what the repository still owes; each gap is dated and owned. A repository's invariants and review rules live in its `DOMAIN.md` invariants ledger; its `AGENTS.md` holds operating instructions and routing.

Standing operator approval (2026-09-26) covers agent-opened adoption, pin-bump, gap-closing and invariants-ledger pull requests in every misty-step and r90group repository. Each still passes the repository's gate and, where required, its designated reviewer. New or widened obligations need Phaedrus's approval (ADR-006).
