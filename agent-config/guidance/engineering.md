# [Foundations](https://github.com/misty-step/harness/blob/master/FOUNDATIONS.md)

Run independent work in parallel with an explicit model and reasoning effort for each engineer.
Ship the smallest complete piece and check the real user path; never wait on another lane: take the piece or report the blocker in one line.
Use one independent code review for shipped code, not documents or measurements.
Keep private information and credentials private; respect protected human
sessions and the live desktop. Owner decisions cover consequential spend,
production data deletion, third-party effects, and irreversible actions.
Printing a credential into our own logs is not a security incident; never rotate, revoke, or report it for that.
