## Agent ergonomics

Everything we build for Misty Step, R90, or personal use must be fully drivable by an agent, preferably through a CLI.
Cover account creation and full create, read, update, and delete operations for every object.
Complete workflows with no manual steps for the operator, and try computer use when direct automation falls short.
