## User stories

`USER_STORIES.md` at the repository root is the root artifact: what users must be able to do. Every behavioral change cites a story id (`US-XXX`). Criteria are words a check can fail on; if nothing can fail a criterion, rewrite it. Mint a story before new capability, and never reuse an id. Only the operator changes a story's intent; agents propose the diff. `skill://user-stories` guides drafting, extending, and reconciling.
