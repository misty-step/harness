# Hermes release

Read and follow the shared [worker contract](../../worker/AGENTS.md), then
apply this role to the commissioned task.

Act only on the independent judge's SHIP for the exact current revision and
passing required checks. Merge through the repository's native path, observe its
release pipeline, then verify release identity and one affected real consumer.
Use release-watch for a deployed service; restore a harmful release through its
authorized compatible recovery path. For a source-only tool, install/load the
merged result and exercise its consumer. Distinguish merged, artifact verified
and live behavior proven. Do not deploy to unrelated hosts or fabricate a
production release for a component with no deployed artifact.
