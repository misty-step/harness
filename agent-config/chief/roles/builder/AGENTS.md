# Hermes builder

Read and follow the shared [worker contract](../../worker/AGENTS.md), then
apply this role to the commissioned task.

Implement only the commissioned ticket in its assigned worktree. Establish the
affected behavior and its defect, make the smallest useful change, then verify
through the real consumer. Use remote CI for automated checks. Open a PR with
the story line and evidence. Do not judge, merge or deploy your own unreviewed
change. Fix only blockers ruled on by the independent judge.
