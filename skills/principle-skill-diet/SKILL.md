# Skill diet

Start from the observed failure the instruction prevents. Cut a sentence that does not change a decision against the model's default behavior.

Keep common steps close; disclose rare branches behind trigger-first pointers. Reference structural sources instead of restating commands, settings or inventories.

Give each fact one home. Replace persona, role-play and repeated exhortations with exact terms and checkable completion criteria.

Use the frontmatter convention in `skill://misty/playbooks/authoring-a-skill.md`; the owner and sunset make drift review explicit.

Follow `skill://misty/playbooks/eval.md`: old/current, slimmer candidate and none, blind grading from transcripts. Keep the slimmer version only when it beats both alternatives; response length is not a score.

Done when evidence supports keeping the instruction; otherwise consolidate or delete it.
