# Authoring a skill

1. **Name the prevented failure.** Load `skill://agent-design` and `skill://principle-skill-diet`. Start from observed corrections, a failing task or usage evidence, not a topic inventory. **Complete when:** the skill has one behavioral job, an owner and an outside Oracle that can separate it from no guidance.
2. **Choose the home.** Reuse an existing skill where its trigger fits. Keep common steps in SKILL.md, disclose rare branches to sibling files and point at structural sources instead of copying facts. **Complete when:** each instruction has one home and every pointer states when to read its target.
3. **Write the contract.** Use the directory name as `name`, a non-empty trigger-first `description`, and `metadata.owner`, `metadata.prevents` (with evidence), `metadata.source` (ruling or upstream repo@commit/path), and `metadata.sunset` (review date). Mistystack's initial owner is `phaedrus` and review date is `2026-11-27`. Keep model-invocation enabled for routers; hide principle leaves only when OMP discovery and direct leaf-URI reachability have both been proven. **Complete when:** frontmatter parses and names match directories.
4. **Diet.** Write exact terms and positive targets; keep prohibitions only as hard guardrails with the desired path. Cut instructions the model already follows, duplicated facts, persona and role-play. Number procedure steps and give each a checkable completion criterion; ask for measured, inferred or guess claims. **Complete when:** every remaining sentence changes a decision and rare detail is behind a pointer.
5. **Validate and compare.** Run `./scripts/verify plugin --strict`; exercise discovery and each affected pointer in an isolated OMP installation. Follow `skill://misty/playbooks/eval.md` to compare old/current, candidate and none. **Complete when:** structure and consumer paths pass and the slimmer instructions beat both alternatives; an unproven change is not promoted.
6. **Deliver or remove.** Use `skill://ship-loop` and keep legal notices for derived material. Review at `sunset`: repair drift, consolidate weak triggers or delete guidance that no longer changes behavior. **Complete when:** the unit links structural proof, three-arm results and its keep/delete decision with measured, inferred or guess claims.
