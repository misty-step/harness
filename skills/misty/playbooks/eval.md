# Eval

1. **Precommit the trial.** State the behavior under test, representative organic tasks, exact outside Oracles, repeats and promotion rule. Compare three arms: old/current instructions, candidate instructions and no instructions. Reserve the rubric for the judge. **Complete when:** all three arms, the same task set and a pass rule are fixed before runs begin.
2. **Isolate and blind.** Give every run a fresh OMP session and isolated worktree with identical inputs, tools, model and limits; vary only the instruction arm. Use neutral project-shaped paths and labels. Candidate-visible prompts and paths reveal neither trial, arm, rubric nor other candidates. **Complete when:** the arm map is outside candidate and judge context and an ordinary user request can run unchanged in all arms.
3. **Run.** Use OMP's `task` tool for independent workers through misty's briefing contract; keep hidden trial metadata out of their briefs. Preserve complete tool transcripts, diffs, token usage and Oracle output outside the checkout. **Complete when:** every scheduled run has artifacts and a terminal result; missing or refused checks are unproven, not passes.
4. **Judge blind.** An independent judge sees sanitized labels, tasks, artifacts and the same rubric, never arm or model identities. Score Oracle pass, net LOC, special cases, taste and tokens. Taste covers domain fit, interface depth and reader load; fewer lines do not excuse broken behavior. Never score response length. **Complete when:** each score names observable evidence and every arm is graded on one scale.
5. **Grade the chain.** Inspect the actual OMP transcripts for files read, decisions made and checks exercised. Grade adherence from tool events and artifact shape, not the worker's self-report. **Complete when:** claimed instruction effects are traceable to the run, and unrelated private sessions were not read.
6. **Decide.** Reveal the arm map only after grading. Keep the candidate only when it beats both old/current and none under the precommitted rule; otherwise retain the supported baseline or delete ineffective guidance. **Complete when:** the report links the rubric, per-arm measurements, blinded verdict, uncertainty and promotion decision, with measured, inferred or guess claims.
