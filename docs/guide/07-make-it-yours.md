# 7. Make it yours

Change models and reasoning budgets through [setup-mistystack](../../skills/setup-mistystack/SKILL.md). OMP profiles let different environments keep separate settings. Project overrides belong in that project's native OMP configuration; setup checks whether they shadow a global role.

Keep project terms in `DOMAIN.md`, behavior in `SPEC.md`, consequential decisions beside the code, and local agent constraints in `AGENTS.md`. Link to this method instead of copying it. Use [agent-design](../../skills/agent-design/SKILL.md) when a project needs a new skill or instruction.

Mistystack installs its own method only. The [reference list](../references.md) is reading material, not another set of installed packs. Private workstation configuration and fleet machinery live separately in `misty-step/workstation`; they are not part of this public method plugin.
