# 4. Build

Use [misty's playbooks](../../skills/misty/SKILL.md) for the kind of work in hand. Keep the project's domain names and public behavior intact while changing its implementation.

[Ship-loop](../../skills/ship-loop/SKILL.md) carries a shaped slice through building, proof and review. Its rigor roles resolve through the models selected in setup; changing a model does not require editing the method.

Give independent workers independent slices with the same outside check and explicit boundaries. Bring their work together before running shared checks. A blocked part does not stop work that can finish safely.
