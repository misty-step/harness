**Scope.** The operator's 2026-09-26 go on the revised slate: every model on
OpenRouter with no subscription, DeepSeek V4.1 Flash as System 2, Xiaomi's
MiMo-V2.6-Pro as the advisor, the Jev-gated advisor first, the three
contestants (Pi with System 1, plain Pi, and the OMP rig) in every experiment,
and a pause before total spend passes $20.

## Setup

| Item | Value |
|---|---|
| Machine | The harness project's exe.dev workspace `harness-ws` (2 vCPU, 7 GB), one run at a time, arm order shuffled per task (seed 26) |
| Isolation | Agent user `evalagent`, fresh base-only checkout per run, hidden tests and every other run unreadable to it, remote-reaching tools shimmed off |
| Network | The agent reaches only the runner's model boundary on loopback; the runner refuses to start while it can reach GitHub, the exe.dev gateway, an arbitrary address, or another local service |
| Key | No key on the VM: the boundary forwards to an exe.dev http-proxy (`s1s2-openrouter`) that injects `workstation/OPENROUTER_API_KEY_MIRRODIN_PI` |
| System 2 | `deepseek/deepseek-v4.1-flash` on DeepSeek's own endpoint, reasoning high, output ceiling 384,000 (round 1's) |
| Advisor | `xiaomi/mimo-v2.6-pro` on Xiaomi's endpoint, reasoning high: System 1's advisor, OMP's Steward, and System 2 in the strong arm |
| Jev | `typesafe/jev-1.13` through OpenRouter's Decisions route |
| Tasks | 12 merged misty-step/harness pull requests, 4 small, 4 medium, 4 large; each withholds the pull request's own tests |
| Judges | GLM-5.3 and MiniMax-M3 on OpenRouter plus the Jev panel, blind to arm names, metrics, and tests; labels shuffled per task and judge |
| Spend guard | The boundary admits a call only while settled cost plus every unsettled call's worst case fits the pass's cap |

Each model is forced onto one upstream with fallbacks off. The runner reads
each pinned endpoint's prices and output limit; System 2's output ceiling is
capped at the endpoint's own limit (131,072 on the Xiaomi, Z.AI, and Alibaba
endpoints).

## Calibration before any live run

Every new Jev threshold was set on round 1's recorded runs
(`eval/jev-replay.ts`), not tuned on round 2.

| Question | Replay | Threshold chosen | What it does on the replay |
|---|---|---|---|
| Advisor gate: would a review change the next step? | 1,177 turns of 30 Pi runs | 0.55 | 1.9 gate consults per run (0.7 would give 0.3) |
| Effort: is the next step routine? | same turns | 0.6 | 29% of turns run with reasoning off |
| Checklist: is a requirement still unmet? | 36 final diffs | 0.22 | about a third of runs sent back; Jev's highest unmet probability never passed 0.30 and did not track hidden failures |
| Trim: does the agent still need an old output? | 954 outputs at 83 trim points | below 0.3 trims | 59% of eligible old outputs trimmed |
| Reset: would a fresh start help? | 235 turns past 40 in 15 runs | 0.4 | 4 of 15 long runs reset, the 86-turn run among them |

A MiMo sample of ten consults on the recorded runs cost $0.028: reviews at
gate points took 10 to 19 s, final reviews 49 to 94 s, and one passed 120 s.
One reply left its advice string unterminated. The consult timeout moved to
180 s and the parser reads the two fields one by one when the JSON does not
parse.

DeepSeek V4.1 Flash on its own endpoint does not honor low or medium effort
(two low-effort calls used 443 and 2,199 reasoning tokens, two high-effort
calls 1,085 and 1,143), so the effort arm switches reasoning off rather than
lowering it.

## Decision rules, fixed before the results

Written at 20:10 UTC on 26 September, with 5 of 12 tasks through experiment 1
and nothing else run:

- **Best System 1 version for the model check (experiment 4).** Pi with
  System 1 alone, unless another System 1 arm beats it on judged quality with a
  95% interval above zero, or cuts billed cost with an interval below 1× while
  its quality interval stays above −0.25 points (round 1's quarter-point
  rule). If several qualify, the larger quality gain wins, then the lower cost.
- **Experiment 7 (hand flagged turns to MiMo).** Runs only if MiMo doing the
  work beats Pi with System 1 on judged quality with an interval above zero;
  otherwise it is skipped, as the slate specified.
- **Every other experiment** is reported against its reference with its 95%
  interval, and called a change only when that interval excludes no change.
